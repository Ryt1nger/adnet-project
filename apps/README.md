# Apps

Application entry points for the Adnet product.

This directory is intentionally a non-functional skeleton. Product code should be added module by module on dedicated branches.

## Planned Apps

- `mini-app/` - the user-facing Telegram Mini App.
- `api/` - backend API and domain workflow engine.
- `admin-web/` - private operations and moderation panel.
- `telegram-gateway/` - Telegram entrypoint, deep links, and notifications.
